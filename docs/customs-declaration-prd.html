2. 项目目标

将合同、发票、装箱单、提单等报关资料沉淀为一张可追溯的报关订单，支持资料识别、人工核对、审核、草单下载与关贸云申报。

本期交付目标：

  1. 建立统一订单编号和完整订单状态流转。
  2. 支持业务员从创建订单到提交审核的完整处理链路。
  3. 支持审核主管审核通过或填写原因驳回。
  4. 支持待申报订单推送关贸云，并保留下载和推送留痕。
  5. 支持客户、商品、HS Code、HS 要素作为可复用基础资料。

3. 角色与边界

角色 主要权限
业务员 新建、编辑待提交订单；上传 / 解析 / 回填资料；下载草单；提交审核；复制、预览订单。
审核主管 对待审核订单进行审核通过或审核驳回。
系统 生成编号、保存版本、执行 OCR、生成草单、记录下载 / 操作日志、调用关贸云。

本期不包括登录、组织与数据权限的正式实现；研发需预留当前用户、所属组织、角色权限和审计字段。

5. 核心业务流程

stateDiagram-v2
  [*] --> 待提交: 新建 / 复制
  待提交 --> 待审核: 确认提交
  待审核 --> 待提交: 审核驳回（填写原因）
  待审核 --> 待申报: 审核通过
  待申报 --> 已申报: 关贸云推送成功

状态 定义 是否可编辑 关贸云路径
待提交 新建草稿、资料待补录或审核驳回后待修改 是 未同步
待审核 已确认提交，等待审核人处理 否 未同步

已申报 已成功推送关贸云 否 已同步

状态标签颜色：待提交橙色、待审核红色、待申报绿色、已申报蓝色。

6. 报关订单工作台

6.1 统计与筛选

  1. 顶部统计卡展示待提交、待审核、待申报、当前列表四类数量。
  2. 点击统计卡，自动以对应状态筛选列表。
  3. 支持以下筛选字段：客户名称、合同号、发票号、提单号 / 运单号、报关状态。
  4. 支持查询与重置；默认按订单最近更新时间倒序。

6.2 列表字段

列表字段采用可配置模式。用户可在“字段可调整”中按个人或租户配置新增、隐藏、恢复默认和拖拽排序；字段配置仅影响列表展示，不影响订单数据、筛选能力或状态流转。订单编号与操作列默认固定展示，其他业务字段均可按需调整。

默认字段

字段 展示与规则
订单编号 创建时生成；蓝色链接；任意状态可打开只读预览。
客户名称 只显示客户名称，不拼接合同和发票信息。
合同编号、提运单号、报关口岸 为空时显示“待补录”。
件数、重量、金额 分列展示；金额含币制。
订单状态 显示状态标签；待申报额外显示蓝色纸飞机推送入口。
关贸云路径 仅已申报显示“已同步”；其余状态统一“未同步”。
提审时间 提交审核时写入；未提交显示“—”。
下载记录 无记录显示“—”；有记录显示次数，悬停 / 聚焦后展示下载人、时间和格式。
操作 固定展示编辑、复制、下载、提交、审核、删除六项，按状态灰显。

可增加字段

字段 展示与规则
发票号 显示订单关联的商业发票号；为空显示“待补录”。
统一社会信用代码 显示客户统一社会信用代码；为空显示“—”。
B/L No. 显示提单补充编号；为空显示“待补录”。
起运港、目的港 分别显示起运港与目的港。
贸易方式 显示贸易方式及代码。
运输方式 可选显示运输方式；默认不展示。
包装单位 显示包装单位。
毛重、净重 分列展示重量及单位。
币制 显示订单币制；多币制订单显示“多币制”。
创建时间、最近更新时间 用于按时间判断订单处理进度。

状态编辑复制下载提交审核删除
待提交可用可用禁用可用禁用可用
待审核禁用可用禁用禁用可用禁用
待申报禁用可用可用禁用禁用禁用
已申报禁用可用可用禁用禁用禁用

不可用操作必须保留位置、灰色显示、不可点击。

6.4 列表操作规则

操作 触发与结果
新建 跳转新建订单页。
编辑 打开订单详情编辑模式。
预览 点击订单编号，以只读方式打开订单详情。
复制 复制订单基础信息、商品、附件；生成新订单编号；状态设为待提交。
删除 仅待提交可删除；显示二次确认；删除订单及其关联明细。
提交 显示“确认提交订单？”弹窗，确认后更新为待审核，写入提审时间和操作日志。
审核 仅待审核可进入审核模式。

7. 新建订单

7.1 字段与校验

字段 是否必填 规则
客户名称 是 支持客户名称、客户代码、统一信用代码联想；允许直接手工填写。
客户代码 否 选择客户后自动带入。
统一信用代码 否 选择客户后自动带入，可修改。
合同编号、发票号、提运单号 否 可先为空，在详情继续补充。
报关口岸 否 可人工填写或由识别结果回填。
运输方式 否 海运整箱、海运拼箱、空运、陆运。
贸易方式 否 一般贸易、进料加工、来料加工。

7.2 提交结果

  1. 点击“下一步”时创建订单、生成唯一订单编号。
  2. 新订单状态默认为待提交，关贸云路径默认未同步。
  3. 创建成功后进入订单详情编辑模式。

8. 订单详情

8.1 页面模式与顶部操作

模式 可见操作 可编辑性
编辑 复制订单、下载、保存草稿、提交审核 可编辑
预览 复制订单、下载 只读
审核 审核通过、审核驳回 只读
待申报 / 已申报 复制订单、下载 锁定

下载下拉菜单在列表与详情保持一致：

菜单项 输出
关贸云推送单 Excel 格式草单。
核对草单 PDF 格式草单。

每次下载需记录订单、格式、下载人、下载时间，并写入订单处理记录。

8.2 文件上传与 OCR

功能 规则
文件列表 显示文件名称、状态、耗时、错误摘要、解析 / 预览 / 删除操作。
上传材料 新增补充材料，默认待解析。
单文件解析 可独立解析单个文件。
一键解析 对已上传且可识别的材料批量发起解析。
文件预览 弹窗显示源文件预览与可复制的识别字段文本。
回填 只有主动点击“回填”后才写入订单字段；不可直接用 OCR 覆盖人工录入。
锁定限制 待审核、待申报、已申报状态不允许上传、解析、回填、删除。

回填范围：报关信息、商品明细、随附单证。回填后仍允许人工核对和修改。

8.3 报关信息

字段包括：客户名称、统一信用代码、合同号、发票号、提运单号、B/L No.、报关口岸、贸易方式、运输方式、启运港、目的港、件数、包装单位、毛重、净重、币制、总金额、备注。

提交审核前需校验以下字段：客户名称、统一信用代码、发票号、提运单号、报关口岸、贸易方式、运输方式、净重、总金额。缺失时禁止提交，并提示缺失数量。

页面需要展示“已填写数 / 应填写数”；备注不纳入完整度统计。

8.4 商品明细

功能 规则
商品字段 项号、货物描述、产品编码、HS Code、中文品名、规格型号、数量、单位、总价、币制、申报要素。
行维护 支持新增、复制、保存、删除；删除前二次确认。
项号 新增、复制、删除后自动连续重排。
表头汇总 订单编辑页的商品明细表头实时显示：总项数、HS Code 数、数量合计、总价合计；总项数显示在“项号”右侧，HS Code 数显示在“HS Code”右侧。
汇总口径 HS Code 只统计有效编码并去重；金额必须按币制分组，不得跨币制直接相加。

8.5 报关附属资料

资料分类：许可证、集装箱、随附单证、所需单证、企业资质、VIN。

  1. 每个分类使用独立表格维护数据。
  2. 每类可新增、编辑、保存、删除。
  3. 切换分类后保留当前订单资料。
  4. 订单锁定时不允许修改附属资料。

8.6 处理记录

记录以下会影响订单或状态的事件：新建、复制、上传、解析、回填、保存、商品 / 附属资料变更、提交、审核通过、审核驳回、草单下载、关贸云推送。

每条记录至少保存：订单 ID、事件类型、操作人、发生时间、描述、扩展数据（可选）。

9. 审核与关贸云申报

9.1 审核

  1. 待审核订单从列表进入审核模式，订单资料必须只读。
  2. 审核通过后：订单状态更新为待申报，关贸云路径更新为未同步，订单继续锁定。
  3. 审核驳回时：必须输入原因；订单退回待提交，恢复编辑、提交、删除权限；原因写入处理记录。

9.2 关贸云推送

  1. 仅待申报订单展示蓝色纸飞机入口。
  2. 若订单存在任意草单下载记录，点击纸飞机先弹出确认：“当前单据已下载过关贸云表格，请确认是否推送。”
  3. 若无下载记录，点击纸飞机直接调用推送。
  4. 推送成功：订单状态变为已申报，关贸云路径变为已同步，写入推送与处理日志。
  5. 推送失败：保留待申报和未同步，记录失败原因，并允许后续重试；该项需要正式接口实现。

10. 基础资料

10.1 共性能力

四类基础资料均支持：查询、重置、导入、新增、编辑、保存草稿、提交审核、审核通过、启用 / 停用。

新增 / 编辑采用弹窗，两列标签与输入控件对齐；必填星号必须显示于字段标签内，不能挤占输入列。

10.2 模块规则

模块 关键字段 / 规则
客户资料 客户代码、客户名称、统一信用代码、状态、最近更新；客户代码唯一。
商品资料 内部商品编码、中英文品名、品牌、材质、状态；内部商品编码唯一。
HS Code HS Code、品名、法定单位、税率、监管证件、申报要素、版本、生效日期；HS Code 必须为 10 位数字且唯一。
HS 要素 HS Code、要素编码、要素名称、来源、状态；来源固定为“企业自填”，唯一键为 HS Code + 要素编码。
  1. 基础资料保存草稿后不可作为正式可复用数据。
  2. 审核通过后资料可启用，并可在订单中进行联想或回填。
  3. HS Code 的申报要素可按序号自动拆分为 HS 要素记录。

11. 数据模型与接口建议

实体 关键内容
order 订单编号、状态、客户 / 单证 / 港口信息、金额、提审时间、审核原因、同步状态、创建 / 更新时间。
order_file 文件类型、文件名、存储地址、解析状态、耗时、错误摘要、解析结果版本。
order_goods 项号、产品编码、HS Code、品名、规格、数量、金额、币制、申报要素。
order_attachment 附属资料分类、行号、字段 JSON。
order_event 事件类型、操作人、操作时间、描述、扩展数据。
order_download_log 文件格式、下载人、下载时间、文件版本。
guamaoyun_push_log 请求报文、响应报文、状态、失败原因、重试次数、关贸云流水号。
customer / product / hs_rule / hs_element 基础资料的主数据与生命周期状态。

建议接口组：订单及状态流转、文件上传与 OCR、商品及附属资料、草单生成与下载、关贸云推送与回执、基础资料维护与导入。

12. 验收标准

  1. 可完成“新建 → 上传 / 解析 / 回填 → 补录 → 提交 → 审核通过 → 推送 → 已申报”的完整链路。
  2. 四种订单状态在列表与详情中的可编辑性、颜色、同步状态和操作权限完全符合第 5、6.3 节。
  3. 只有已申报显示已同步；其余状态均显示未同步。
  4. 待申报订单有下载记录时推送必须确认；无记录时直接推送。
  5. 审核驳回必须填写原因，订单必须回到待提交且恢复可编辑。
  6. 下载 Excel / PDF 均写入下载记录和订单处理记录。
  7. 商品汇总实时更新，HS Code 去重，金额不跨币制相加。
  8. 基础资料弹窗字段文本、必填星号和输入框在各资料类型下保持对齐。

13. 研发待确认项

  1. 登录、组织、角色、审核权限与数据权限规则。
  2. OCR 文件类型、最大大小、异步任务模式、置信度和人工差异处理方式。
  3. 关贸云认证、字段映射、推送回执、异常码、失败重试和报关号回写机制。
  4. Excel 推送单与 PDF 核对草单的正式模板、文件归档与下载权限。
  5. 订单删除的逻辑删除策略、审计留存期限及已申报订单是否允许作废。
  6. 多币制金额的展示币种与汇率换算策略。
